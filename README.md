# Câmera Nobre 📸

Aplicativo de fotografia imobiliária profissional desenvolvido sob medida para o **Samsung Galaxy S25 Ultra**.

## Recursos Principais
- **Perfil de Cor Imobiliário**: Ponto de preto ancorado que elimina a camada esbranquiçada/leitosa dos pisos de porcelanato e tetos de gesso. Realce inteligente de madeiras e jardins.
- **Sessão por Imóvel**: Salvamento direto no álbum correto da Galeria (ex: `IMÓVEIS 2026/Alphaville I B29 - Clóvis`), acabando com a necessidade de triagem manual.
- **Geolocalização Integrada**: Gravação de tags EXIF com GPS de alta precisão para abrir o mapa interativo nativo na Galeria Samsung.
- **Resolução Otimizada**: Alternância rápida de 1 toque entre **12 MP** (dia a dia, alta luminosidade, rápido) e **50 MP** (máximo detalhe).
- **Nível Virtual**: Sensor em tempo real que fica verde quando a câmera está 100% nivelada, mantendo as paredes perfeitamente verticais.
- **Takes de Vídeo para o CapCut**: Alternância rápida para gravação de takes curtos para edição de reels.

## Como Compilar o APK no GitHub (Direto pelo Celular)
1. Crie um repositório no seu GitHub chamado `camera-nobre`.
2. Envie os arquivos deste projeto para lá.
3. A automação do **GitHub Actions** vai compilar o arquivo `.apk` em 2 minutos.
4. Baixe o instalador na aba **Actions** e instale no seu S25 Ultra.
